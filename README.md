🚀 **Built my own AI-powered Research Paper Assistant using RAG!**

I've been exploring Retrieval-Augmented Generation (RAG) and decided to build a practical project to understand how it works beyond the theory.

Introducing my **Research Paper RAG Assistant** 📚

The application allows users to:
- Upload and work with multiple PDF documents.
- Ask questions about research papers using natural language.
- Retrieve relevant information using semantic search.
- Compare a research paper with a resume.
- Identify direct matches, transferable skills, and missing skills.
- View source documents and page references for answers.

🛠️ **Tech Stack:**
- Python
- Streamlit
- FAISS
- Sentence Transformers
- Ollama (Qwen 2.5 3B)
- PyPDF

One of my biggest learnings was understanding that retrieving relevant information isn't enough. Preventing hallucinations, maintaining document context, and grounding answers in source evidence are equally important.

This is an ongoing learning project, and I'm looking forward to improving its retrieval accuracy and document comparison capabilities.

Building, experimenting, learning, and improving! 💻
